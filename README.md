# Elements, Align.

[![Engine](https://github.com/club-paradiso/elements-align/actions/workflows/engine.yml/badge.svg)](https://github.com/club-paradiso/elements-align/actions/workflows/engine.yml)

> Find where you align.

A location-, direction-, time- and person-aware ambient Apple Watch experience
drawn from East Asian traditional cosmology.

Not a horoscope app. The wearer turns their body; the watch responds. When
person, time and direction line up, the interface lines up.

```
Quiet → Unsettled → Neutral → Favourable → Strong → Aligned
```

At full alignment the five elemental nodes converge, a single restrained haptic
fires, and the composition resolves:

```
ELEMENTS,
ALIGN.
```

## How the maths is verified

The part of this product that has to be correct is the engine, and it is
checked against sources outside this project rather than against itself.
`Tools/oracle/` is an independent Python implementation of the same maths:

| Claim | Checked against | Result |
| --- | --- | --- |
| Apparent solar longitude | Untruncated VSOP87, 1900–2100 | 0.395″ worst case (~9.6 s) |
| Solar terms | Published 2026 & 2000 equinoxes/solstices | within ~1 minute |
| Equation of time | Textbook annual landmarks | −14.17 Feb · +3.67 May · +16.45 Nov |
| Year pillars | Published sexagenary years | exact |
| Day pillar formula | Two independent sources; 2000-01-07 = 甲子 | exact |
| Eight Mansions | Classical 坎 row, all 8 directions | exact |
| Relation symmetry | Structural property of the system | 0 asymmetric pairs |
| Life gua | Per-century rules, 1900–2060, both polarities | 0 mismatches |

The 104 Swift tests assert against fixtures generated by that validated
oracle, so they check this implementation rather than themselves, and several
assert against the external values directly. Every one of them passes.

Writing them found two real bugs and one incorrect test before anything was
committed; CI then found two more. Details in
[BUILD_STATUS.md](Documentation/BUILD_STATUS.md).

## Platforms

- **iPhone** — onboarding, birth details, Five Element profile, permissions,
  settings, engine inspector. iOS 17+.
- **Apple Watch** — the ambient experience. watchOS 10+, **Series 5 or later**
  for the compass.

Swift 5.9, SwiftUI, no third-party dependencies.

## Build

The engine needs no Xcode and builds anywhere Swift runs, including Linux.
This is what CI does on every push:

```sh
make test        # build and test the engine
make syntax      # parse every Swift file (needs no toolchain at all)
```

The apps need macOS. The `.xcodeproj` is generated rather than committed:

```sh
brew install xcodegen
make project
open ElementsAlign.xcodeproj
```

Set `DEVELOPMENT_TEAM` locally; it is deliberately empty in `project.yml`.

## Architecture

```
Packages/ElementsAlign/Sources/
├── ElementsCore/      deterministic domain logic — Foundation only
├── ElementsSpatial/   heading maths + CoreLocation adapter
└── ElementsDesign/    design tokens + presentation logic
Apps/{iOS,watchOS,Shared}/
Tools/{oracle,syntaxcheck}/
```

One rule holds the whole thing up: **computation never touches presentation.**
`ElementsCore` imports Foundation and nothing else — no SwiftUI, no
CoreLocation, no networking, no display strings. That is what lets the
important part be tested on a machine with no Apple SDKs at all.

A second structural rule keeps it usable on a wrist: the solar-term solver
never runs on the heading path. Charts are built once, the moment's pillars are
rebuilt only when the hour turns, and per-update work is arithmetic.

## What Alignment is

> A deterministic symbolic score produced from selected traditional
> cosmological rules and current contextual inputs.

Four Pillars (BaZi), Five Elements (Wu Xing) and Eight Mansions (Ba Zhai) are
traditional belief systems. This product applies their rules faithfully and
deterministically. It does not claim they measure anything physical, and it is
never a health, psychological, financial or safety assessment, nor a
prediction.

No language model is involved in producing a result. Everything is
deterministic code.

Where practitioners genuinely disagree — the late Zi hour, which elements a
chart favours — the disagreement is recorded and one option chosen explicitly.
Where a number is a product decision rather than a tradition, it is labelled as
one.

## Privacy

Birth details and location stay on the device. No account, no sync, no
analytics carrying them, no server-side calculation, no AI service.

The app makes **no network requests** — there is no backend and no dependency
that could make one. Birth places come from an offline table precisely so that
geocoding a birth city could not make that claim untrue.

[Documentation/PRIVACY.md](Documentation/PRIVACY.md)

## Design

Minimal, calm, spatial. No dragons, no gold, no mystical gradients, no
fortune-cookie language. Elements are drawn as a considered family — Wood a
muted celadon, Fire a warm ember, Water an ink blue — not as their literal
substances.

The state ramp is ordered by lightness in both colour schemes, so state reads
without relying on colour perception; every step clears 3:1 contrast, and both
properties are asserted in tests. Reduce Motion collapses every duration.
